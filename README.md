# soft-nook-tool

Edge Computing · Compilers · Observability

学习用的示例项目

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/soft-nook-tool.git
cd soft-nook-tool
npm install
```
